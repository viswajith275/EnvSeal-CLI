03 — The Seal

Chaos collapses into
one encrypted artifact.

The vault is a single file. It lives in your repository, tracked by Git like any other source file — because it is ciphertext, and ciphertext is safe to commit.

$ envseal init --local

Creates .envseal — an Age-encrypted vault bound to your local identity key. Plaintext never touches the repository, and never leaves your machine.

06 — Git-Setup

One command installs
the guardrails.

envseal git-setup writes a pre-commit hook and registers a custom merge driver. The hook bounces raw plaintext back. The driver resolves vault conflicts without a diff editor in sight.

Plaintext secrets exist only inside the child process you launch. When that process exits, the secrets are gone. No temp files. No shell history. No /proc leftovers.

08 — Scoped CI & Global Vault

Borrow exactly what CI needs.
For exactly as long as it needs it.

Never paste your personal SSH or Age key into a CI runner. A CI token is a temporary, scoped channel into the vault — limited by tag, by key, and by an expiration. Separately, your personal configuration lives outside any repository in a Global Vault.

Scoped CI token

envseal token --tag prod \ -o ./ci.token --exp 3600 \ STRIPE_SECRET DATABASE_URL
✔ token written to ./ci.token scoped to: STRIPE_SECRET, DATABASE_URL expires: 3600s (CLI-enforced)

Token expiry is enforced by the CLI, not by cryptography. A sufficiently determined attacker with the raw payload could bypass the clock check.

Global developer vault

$ envseal --global init
$ envseal link myapp ✔ linked myapp → global vault

Perfect for personal scripts and utility tokens. Keep one system-wide vault, independent of any Git repo, and attach it to as many local directories as you like.

09 — Engineering Candor

Things worth knowing
before you trust us.

Every tool has an edge. Cryptography is very good at math and very bad at knowing whether you meant to leave the front door open. These are our limitations, stated plainly.

01
Removing someone doesn't erase what they already saw.
envseal recipient rm stops a person from decrypting future commits, but Git history is permanent. Anyone who cloned the repo earlier still has old encrypted commits and could decrypt them with a key they already hold. Always rotate the actual credentials.
02
envseal rotate protects the future, not the past.
Rotation generates new key material and re-seals the current vault, which is exactly what you want after a compromise. It does not retroactively re-encrypt old Git commits. If a token leaks, rotate the vault and the actual API keys at the source.
03
Token expiry is enforced by the CLI, not by cryptography.
The --exp flag is a runtime check performed by EnvSeal itself. Because everything is offline, there's no server refusing an expired token. It is a guardrail, not a cryptographic guarantee.
04
If you're your only recipient, you're also your only point of failure.
There is no cloud backup, no support ticket, and no admin override that will get your secrets back. EnvSeal has no "forgot password" button. Treat your Age/SSH identity the way you'd treat a seed phrase, or add a secondary recovery key.

11 — FAQ

Common Questions

Q
Can I use EnvSeal with Docker / Docker Compose?
Yes. Build your image normally, then at runtime do something like:

envseal run -- docker compose up

Or inject only the keys you need directly into the container environment.
Q
Does it work with monorepos?
Yes. You can keep one .envseal vault at the root directory, or use the -e / profile mechanism to manage separate per-package vaults within the repository.
Q
What happens if two people add different secrets at the same time?
EnvSeal registers as a native Git merge driver, so most merges resolve silently in the background. If two contributors change the same key to different values, it stops and prompts you to pick a side via standard Git merge strategies (--ours or --theirs).
Q
Can I still keep a local .env for personal overrides?
Yes, but EnvSeal's pre-commit hook will block you from accidentally committing it. Treat personal overrides as truly local and never stage them.
